Privacy Policy — agent tom

Effective: October 30, 2026

What this app is

agent tom is a personal, single-user application. Its owner uses it, through the open-source tool rclone running on his own Mac computer, to synchronize files between that computer and his own Google Drive.

What data it accesses

With the owner's consent, the app accesses the owner's own Google Drive files (the Google Drive API scope requested by rclone) solely so rclone can list, upload, download, and synchronize those files at the owner's direction.

How data is used and stored

Files move only between the owner's own computer and the owner's own Google Drive. The app operates no server of its own, collects no analytics, and stores no copy of the owner's data anywhere else.

Sharing

No Google user data is sold, shared, transferred, or disclosed to any third party, and it is never used for advertising or any purpose other than the file synchronization described above.

Revoking access

The owner can revoke this app's access at any time from his Google Account's third-party access settings, which immediately stops all synchronization.
