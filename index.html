agent tom

A personal, single-user application

agent tom is a personal application used by its owner to synchronize files between his own Mac computer and his own Google Drive, using the open-source tool rclone with the owner's own Google Cloud OAuth client (Google Cloud project TaskWiz).

It is used by one person only, for his own files. It is not offered to the public, has no other users, and provides no service to third parties.

How the app handles Google user data is described in the privacy policy.
